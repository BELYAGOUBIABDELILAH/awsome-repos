# Contributing

Thanks for your interest in contributing to GitHub Trending Archive.

## How to Contribute

### Report Issues

Found a bug or data quality problem?

1. [Open an issue](https://github.com/BELYAGOUBIABDELILAH/awsome-repos/issues)
2. Include clear steps to reproduce
3. Provide expected vs actual results

### Suggest Features

Have an idea for improvement?

1. Check existing issues first
2. Open a new issue with detailed description
3. Explain the use case and benefits

### Submit Changes

1. Fork the repository
2. Create a feature branch: `git checkout -b feature-name`
3. Make your changes
4. Test thoroughly
5. Commit with clear messages
6. Submit a pull request

## Development

### Setup

```bash
git clone https://github.com/BELYAGOUBIABDELILAH/awsome-repos.git
cd awsome-repos
npm install
```

### Testing

```bash
npm run validate
npm run test
```

### Code Style

- Use meaningful variable names
- Add comments for complex logic
- Follow existing patterns
- Keep functions focused and small

## Pull Request Guidelines

- One feature per PR
- Include tests if applicable
- Update documentation
- Keep commits atomic
- Use descriptive commit messages

## Data Contributions

Help improve repository classifications:

- Add missing topic mappings
- Suggest ecosystem integrations
- Report incorrect categorizations
- Improve use case descriptions

Edit files in `data/ecosystem/` and `config/` directories.

## Questions?

[Open an issue](https://github.com/BELYAGOUBIABDELILAH/awsome-repos/issues) for any questions about contributing.
