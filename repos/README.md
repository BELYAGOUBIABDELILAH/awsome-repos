# Repository Profiles

Complete profiles for every trending repository.

[Back to Home](../README.md)

## What is a Repository Profile?

Each profile includes:

- Stars, forks, language, license, and trending history
- Best use cases and applications
- Ecosystem integrations — what it works well with
- Alternatives solving the same problem
- Complete trending timeline with per-day rank and star gains
- Developer card for quick evaluation

## How Profiles Are Generated

Profiles are automatically generated from:

1. Daily trending data snapshots
2. GitHub repository metadata
3. Curated ecosystem mappings in `data/ecosystem/`
4. Historical trending performance analysis

They are updated on every new trending data import.

## Browse

Profiles are organized by owner name (e.g., `facebook/`, `microsoft/`).
You can also find them linked from [daily reports](../archive/), [topic pages](../topics/), and [language pages](../languages/).
